# Security reporting

Do not disclose credentials, private deployment data, or vulnerability details in a public issue. Use GitHub private vulnerability reporting for this repository when available. For an upstream Michelangelo issue, follow the [upstream security policy](https://github.com/michelangelo-ai/michelangelo/blob/main/SECURITY.md).

Include the affected distribution version, source revision, executable image digest, affected component, and a minimal reproduction with confidential data removed. Dependency findings must identify the installed package and image digest.

See [security and operating boundaries](docs/security.md) for the deployment trust model and customer responsibilities.
